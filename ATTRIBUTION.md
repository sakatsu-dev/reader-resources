# KANJIDIC2 mirror for Sakatsu Reader

An **unmodified** copy of KANJIDIC2, kept at a fixed address so the app's setup can pin it.

The original lives at <https://www.edrdg.org/kanjidic/kanjidic2.xml.gz>, which the EDRDG replaces
in place whenever the dictionary is updated. An exact size and checksum pin on that address breaks
every fresh install at each republication: it happened on 2026-10-13 and again on 2026-10-18. This
copy never changes. A newer KANJIDIC2 is published as a new, separately dated file.
